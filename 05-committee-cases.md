2. **Collection exception.** Use the Vector receipt evidence in the controller's exception records for this case. All other service and collection behaviour follows the signed base. Evaluate the response using information available at each decision date.

4. **Alternate renewal.** Use the alternative H3 wording that excludes use of the original advance against renewal invoices. All other base assumptions remain unchanged. This alternative is executed on H3's signature date in this separate case.
