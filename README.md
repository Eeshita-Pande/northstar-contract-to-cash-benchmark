# Northstar contract-to-cash benchmark

A synthetic compute-financing assignment: build a monthly operating model and a treasury recommendation from a commercial data room, then update the analysis for four committee cases.

Start with [task.md](task.md). All source files are supplied in this repository, including [source-data.xlsx](source-data.xlsx). The data-room documents, bank events and remittance items form part of the assignment.

## Deliverables

Submit the completed `model.xlsx` and `recommendation.md` described in the task. Preserve your first submission and record model/version or analyst, tools, reasoning setting (if applicable), elapsed time and any source questions. A human making an independent attempt should see only these task files before submission.

## Frozen task

This release preserves the ten candidate files used in the 9 October 2026 replications byte for byte. `task-files.sha256.json` records their hashes. The candidate packet is v2.5; the internal review round was called v2.5R1. That label did not modify the candidate instructions or source workbook.

The five replications used isolated environments and finite time allowances. This repository does not set a universal completion-time claim. If reproducing an experiment, record your actual tools and budget alongside the first submission.

This repository contains the assignment only. Review materials are supplied separately after an attempt is complete. The earlier financing-benchmark repository remains a separate, unchanged task release.

All organisations and figures in this exercise are synthetic. No confidential source-company workbook is included.
